KiraCode 是 Kira 系列的一员，旨在把创作 AI 角色卡的能力，从少数人手中，交还给每一个普通玩家。

---

## 项目介绍

KiraCode 是面向 **SillyTavern 生态** 的对话式 AI 角色卡创作工具。

- **核心工作方式**：用户用自然语言下指令，AI 作为 Agent 自动完成角色卡的创建、编辑、优化。
  无需手动拼 JSON，AI 通过结构化的 `card-update` 协议直接改写卡数据。
- **完全兼容 SillyTavern V3** 角色卡格式，含世界书（World Book）、正则脚本（Regex Scripts）、
  封面等全字段，导入导出无损往返。
- **与 Kira 生态的关系**：
  - **KiraKira** —— 体验层；
  - **KiraCode** —— 创作层（本项目）；

## 功能

- **对话式创作**：TUI 风格工作区，用户消息与 AI 消息并排显示，Markdown 渲染。
- **多种工作模式**：会话（讨论）、代理人（工具 + Diff 确认）、全局（YOLO，自动执行）三种模式，另附「制卡师」开关。
- **代理人模式**：ask_user 追问 + submit_plan 计划确认 + Diff 逐条审查，关键修改由用户拍板。
- **全局（YOLO）模式**：不注册交互工具、不挂起等待用户，缺失信息自动补全并标注 ai_guess。
- **Agent 子代理**：真实子代理系统，独立上下文、单一任务、独立模型调用，主 Agent 分配任务并审核结果。
- **制卡师人格**：可训练多张角色卡，提取技术栈、文风、写作习惯、前端工艺生成人格提示词；支持多人格管理与单次启用。
- **用户自定义提示词**：opt-in 注入个人创作偏好（默认不启用，可随时停用且保留内容）。
- **思考强度**：自动 / 低 / 中 / 高 / MAX 五档，自动检测模型支持能力。
- **上下文管理**：可设上下文窗口大小（最大 200 万 token），超阈值自动总结并释放历史。
- **角色卡仓库**：文件存储方案，支持大体积卡，封面与 JSON 分开保存。
- **参考卡选择**：可选参考卡，支持整卡参考或部分条目参考（风格、技术栈、世界书条目、正则条目）。
- **成品区**：完成编辑的卡集中存放，支持导出 PNG/JSON 到 Download，可编辑、添加封面。
- **导入导出**：SillyTavern JSON/PNG 双向，PNG 导出带封面与嵌入元数据（chara + ccv3 双块）。
- **联网搜索**：开启后 AI 按需调用 `web_search` / `fetch_webpage` 工具检索外部资料（关闭时不注册、不宣传）。
- **会话管理**：工作区记录独立入口，支持删除、置顶、改名。
- **数据控制面板**：左侧计划书、子 Agent 状态、token 消耗、缓存命中率、上下文占用；
  右侧设置（模式、参考卡、自定义提示词、制卡师人格、流式输出开关等）。
- **流式输出**：AI 回复逐字显示，可在数据控制面板关闭（关闭后一次性显示）。
- **SillyTavern V3 完整支持**：全官方字段、世界书全位置注入、正则脚本、AI 结构化写入。

## 首次使用

1. 安装 APK 启动，进入品牌页，点击「进入 KiraCode」，首次需同意免责声明。
2. 左上角菜单 → 模型配置：新建配置组，填写 Base URL + API Key，拉取模型并设为激活。
3. 回到聊天界面开始对话，例如「帮我创建一个异世界的角色卡」。
4. 全自动 / MAX 模式下 AI 会先写计划书并自动分步执行。

更多说明见 `docs/` 与 `CHANGELOG.md`。
